# 비자 문호 수동 투입함

국무부 사이트가 자동 수집을 막을 때 쓰는 통로입니다.

1. 국무부 Visa Bulletin 원문 페이지를 브라우저로 엽니다
2. 전체 선택(Ctrl+A), 복사 후 이 폴더에 `2026-12.txt` 같은 이름으로 저장합니다. 페이지를 `.html` 로 저장해 넣어도 됩니다
3. 커밋하면 워크플로가 바로 읽어 6개 언어 페이지와 소식 글을 만들고, 처리한 파일은 지웁니다

표 4개(가족·취업 × 최종조치일·접수가능일)가 모두 읽혀야 게시합니다. 하나라도 빠지면 파일을 그대로 두고 로그에 이유를 남깁니다.
